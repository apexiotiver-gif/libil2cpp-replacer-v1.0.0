# libil2cpp-replacer-v1.0.0

## JitPack Dependency

```
com.github.apexiotiver-gif:libil2cpp-replacer-v1.0.0:v2.0.1
```

## Description

libil2cpp.so replacer library for Free Fire Max using root access.

## Library Structure

```
libil2cpp-replacer-v1.0.0/
├── AndroidManifest.xml
├── R.txt
├── classes.dex
├── classes.jar          (65MB - contains bundled libil2cpp.so)
├── config/
│   └── library.info
├── proguard.txt
└── res/
    ├── anim/
    │   └── accelerate_decelerate_interpolator.xml
    └── values/
        ├── ids.xml
        ├── strings.xml
        └── styles.xml
```

## Requirements

- Root access (Magisk/KernelSU)
- Free Fire Max installed

## Usage

In Sketchware, add this dependency:
```
com.github.apexiotiver-gif:libil2cpp-replacer-v1.0.0:v2.0.1
```
